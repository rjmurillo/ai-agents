# Known-Weak Points: Evidence and Consequence

The full evidence for the honestly-weak parts of the repository structure. SKILL.md Phase 7 keeps the compact list (name plus one-line consequence) so you know the hazard exists while working near it; this reference carries the dated evidence you cite when you act on one.

| Weak point | Evidence (as of 2026-08-19) | Consequence |
|---|---|---|
| Hook sources serve different consumers | Re-verified 2026-08-19: `.claude/settings.json` has 4 events and 6 groups; `.claude/hooks/hooks.json` has 0 events and 0 groups. ADR-096 retired every tool-call hook, so the vendored surface is empty and the generated Copilot tree ships no dispatcher. The previously listed vendored hooks (`require_subagent_model`, `serena_memory_scope_guard`, `serena_worktree_scope`, issues #4874, #5061, #4917) are all deleted | Do not force parity. Verify whether a hook is repository-only or vendored before editing either source |
| `src/claude/` manual dual-edit | `templates/README.md:131` | Shared-template edits silently skip the Claude surface unless you remember the second edit |
| Stale docs contradict reality | Historical: `CONTRIBUTING.md:155` said the removed PowerShell Generate-Agents command until PR #2871 repointed it to `build/generate_agents.py`; zero `.ps1` files exist outside `.venv/` (ADR-042). The `GENERATOR-FILES.md` src/claude misclassification cited here previously is fixed: `.agents/governance/GENERATOR-FILES.md:33-38` now states plainly "`src/claude/` is a hand-maintained copy, not a generator output." Current example instead (found during this 2026-08-18 audit): this skill and `ai-agents-config-catalog` quoted `.agents/SESSION-PROTOCOL.md:30` as "This protocol uses **verification-based enforcement**" and cited `SESSION-PROTOCOL.md:754` for the `SKIPPED: docs-only` verdict string; PR #5135 (2026-08-18, "retire mandatory session-log gates") rewrote the file to 324 lines and removed both | Following docs verbatim fails; quote the canonical source when correcting (FM-9) |
| Ruff debt is ratcheted, not eliminated | `pytest.yml:135-186`, `ruff_ratchet.py`, and `ruff_count_ratchet.py` block changed-file and whole-tree regressions | Existing debt remains, but new violations and count growth block CI |
| Skill tests split by location | `pyproject.toml [tool.pytest.ini_options].testpaths` `testpaths = ["tests"]`; `.claude/skills/<name>/tests/` NOT collected by default; `tests/skills/<name>/` is | Green CI does not prove skill tests ran; run them explicitly (`ai-agents-validation-and-qa`) |
| Proposed-ADR ambiguity | ADR-069 and ADR-072 remain Proposed while proposal-era mechanisms exist; ADR-030 uses a nonstandard status, while ADR-062, ADR-066, and ADR-068 are Accepted | Status field alone is not a reliable "is this binding" signal; check enforcement and amendments |
