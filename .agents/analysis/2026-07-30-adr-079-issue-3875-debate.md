# ADR-079 Issue #3875 Debate Log

## Summary

ADR-079 was re-reviewed under the adr-review skill after issue #3875 measured the traffic assumption in Decision point 4. Verdict: accept. The decision still keeps plugin version bumps at PR time, but the ADR now records that packaged-plugin-source changes appeared in 20 of 60 recent merged PRs (33%) and evaluates the git merge driver option as a separate, unproven mitigation.

## Round 1 Reviews

### Architect

Verdict: Accept.

The ADR keeps the binding architecture intact: PR-time version bumps, no post-merge writes to main, and no new trusted actor. The update corrects the cost model without reversing the accepted decision. The merge-driver option is correctly treated as a separate spike because clone-local configuration cannot become repository policy without more proof.

### Critic

Verdict: Accept.

Issue #3875 directly invalidated the old small-fraction assumption. The revised ADR removes that claim, records both the biased open-PR sample and the stronger merged-PR sample, and states the higher coordination cost plainly. The rejected-options table now covers the new merge-driver option.

### Independent Thinker

Verdict: Accept with reservation.

The merge driver remains the most interesting path because it mechanizes an accepted manual rule without tearing main. The reservation is acceptable because the ADR now names the open questions: pull, rebase, bot merges, clone-local setup, and fail-closed behavior for non-version-only conflicts.

### Security

Verdict: Accept.

The retained decision adds no credential, no branch-protection bypass, and no main-writing bot. The merge-driver option is not adopted because its failure mode must be proven before use. Keeping the strict PR-time gate remains the safest path for preventing stale or downgraded plugin installs.

### Analyst

Verdict: Accept.

The update responds to the measured evidence in issue #3875. It preserves the original #2855 context and adds the 33% merged-PR measurement where the old unmeasured assumption sat. The new regression test pins the measurement, the cost statement, and the merge-driver evaluation.

### High-Level Advisor

Verdict: Accept.

This is the right scope. The owner asked to revisit the assumption, not to ship a new automation mechanism inside this PR. The ADR now accepts the true cost explicitly while leaving a future merge-driver spike open.

## Convergence

All six roles accept the ADR-079 update. No P0 or P1 blockers remain.

## Required Follow-up

If the cost continues to dominate plugin-source work, open a separate spike to test a git merge driver for version-only `plugin.json` conflicts. That spike must prove fail-closed behavior and coverage for pull, rebase, and bot merge paths before proposing policy adoption.
