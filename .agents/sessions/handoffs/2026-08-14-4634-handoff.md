## Decisions Made

- **Keep the early job, delete the late one**: the script exists to abort before
  the 6 to 15 minute hook groups, which only the early position achieves.
  - Alternatives considered: keep the late functional copy (loses the early
    abort and breaks the `mutation-safety` before `push-ref-staleness` ordering
    assertion in `tests/test_mutation_workspace.py`).
  - Reference: issue #4634, `scripts/validation/push_ref_staleness.py` docstring.
- **Pass `"{1}"`, quoted**: lefthook 2.1.10 expands positional arguments;
  `{remote}` is not a template it knows and passes through verbatim. Quoting
  mirrors `commit-message-policy` at `lefthook.yml` line 10 and prevents word
  splitting on remote URLs.
  - Alternatives considered: `{0}` (expands to all arguments, so the URL would
    arrive as a second argument the script ignores); hardcoding `origin` (loses
    the remote the user actually named).
  - Reference: placeholder enumeration in the QA report.
- **A placeholder argument exits 2, it does not fall back to a remote**: an
  unexpanded `{1}` or `{remote}` means the job definition is wrong, so the run
  stops with the ADR-035 usage/configuration code and never queries a remote.
  The first draft warned and checked `origin`; review of PR #4998 showed that
  comparing pushed refs against a remote the caller never named exits 0 on a
  clean comparison nobody asked for, recreating the false green from the other
  side. No argument at all still defaults to `origin`, which direct invocation
  for testing relies on. No repository tooling runs `lefthook run pre-push`
  against the real config without arguments, so nothing legitimate now fails
  (verified by grep over `scripts/`, `tests/`, `.claude/`, and `docs/`).
  - Reference: `TestRemoteResolution::test_placeholder_never_queries_a_remote`,
    `.agents/architecture/ADR-035-exit-code-standardization.md` line 45.
- **Timeout raised 30s to 1m**: `_run` allows `git ls-remote` 10 seconds per
  pushed ref, so 30 seconds is too tight for a multi-ref push. 1 minute is the
  value the deleted copy already used.
