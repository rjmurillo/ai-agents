# Retrospective: PR #5364 needs-split

## What happened

PR #5364 started as one behavior fix: forward `--is-bot` so bot-authored PRs can reach tier T5.
The branch then absorbed three follow-on rounds:

1. command-contract repairs around stale and malformed producer output
2. documentation and evidence-count corrections in the PR body and command prose
3. a focused helper-mode follow-up to cut duplicate `get_pr_context.py` cost

That turned one bug fix into a mixed change set across command prose, helper scripts, generated mirrors, and tests.

## Why commit count grew

- Review feedback landed in several waves on different commits.
- The first implementation fixed correctness before API-cost concerns were raised.
- Generated mirrors and runtime coverage changed in later rounds, so each review fix touched multiple files.

## Better split

Two PRs would have been cheaper to review:

1. behavior fix: bot classification, fail-closed handling, and direct tests
2. follow-up cleanup: focused context helper mode, mirror regeneration, and evidence/body corrections

## Next time

- Land the minimal behavior fix first when the defect is already isolated.
- Treat generated-mirror updates as part of the first patch so later reviews do not reopen parity drift.
- Re-run body-count evidence after each test-shape change before requesting review.
