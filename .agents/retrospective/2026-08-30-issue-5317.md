## Phase 1: Insights Generated
Five Whys:
1. Two script-path mutants survived because the isolated test worktree used the
   committed version of the registry assertion.
2. It used that version because isolated worktrees start from HEAD.
3. HEAD lacked the new exact-registry assertion because the test was not yet
   committed.
4. The harness was run before checking its isolation boundary.
5. The process treated a mutation harness like an ordinary local pytest run.

Root cause: The validation order ignored the mutation harness workspace
contract. This is a near miss in failure mode 4, False Completion Markers,
because reporting mutation coverage from that run would have overstated the
tested behavior.

Patterns and shifts: Structural assertions caught wiring drift, while mutation
tests caught whether those assertions could detect deleted names and scripts.

Learning matrix: Keep aggregate ownership and exact registry assertions. Add a
commit-before-isolated-mutation ordering check. Drop duplicated YAML ownership.
