## Retrospective
Learnings captured:

1. A merge-tree regression can come from any earlier shallow fetch in the same
   workflow job, not only from the fetch directly above the merge-tree step.
   Reproducing the exact shallow history shape is faster than reading the check
   name and guessing.
2. An Aggregate Results failure with every agent at `DID_NOT_RUN` is an
   infrastructure classification problem, not evidence of ten independent code
   findings. Replaying the aggregate script and the critical-failures gate with
   the logged env values proves whether the gate should warn or block.
3. When the fix already exists on `main`, cherry-pick the minimal shared CI
   commit instead of merging the whole branch base if a full merge would create
   a scope explosion with unrelated files.
