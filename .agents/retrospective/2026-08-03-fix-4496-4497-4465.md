## Learnings Captured

### 4497: harness restore failure exit code

The `finally` block in `apply_mutation` called `target.write_bytes(backup)` with no exception
handler. An `OSError` propagated as an uncaught exception, exiting 1, identical to a surviving
mutant. Callers could not distinguish the emergency (could not restore source) from the expected
result (mutant survived).

Fix: wrap in `try/except OSError`, exit 2. Verified with 4 new tests, 2 mutations killed,
1 cosmetic survived.

**Pattern**: Any harness that applies and must reverse a mutation needs exception handling on
the restore write, not just the apply. The OSError path is reachable on low-disk, permission
errors, and concurrent file access.

### 4465: ADR-056 envelope missed in patterns.md

`write_skill_output` wraps all output in `{"Success": True, "Data": <payload>, ...}`. The
patterns.md jq selectors used bare `.AllPassing` and `.PendingCount` instead of `.Data.AllPassing`
and `.Data.PendingCount`. Three lines fixed.

**Pattern**: When reading a skill's output shape, always read the actual source of
`write_skill_output` (`.claude/lib/github_core/output.py`), not the prose description or
another doc. Documentation has been measured wrong repeatedly in this repo.

### 4496: unused monkeypatch params

20 unused `monkeypatch` parameters across 9 test files. The `_clear_ci_env` autouse fixture
in `conftest.py` already provides CI env isolation for all tests. Removing the unused params
reduced taste-lint violations from 595 to 592 (across the full diff).

**Pattern**: When conftest.py defines an autouse fixture for env isolation, individual test
methods do not need `monkeypatch` unless they use it to set a specific value. grep for
`monkeypatch` usages inside each test body, not just the signature.

### Baseline ratchet conflict resolution

When two branches both lower `taste_count_baseline.txt` independently and merge, take the
lower value (more violations fixed is better). The ratchet test asserts `actual == baseline`,
so the baseline must exactly match the tree's violation count, not just be a ceiling.

## Retrospective Section

These fixes retire three small mechanical issues. The larger finding is the exit-code
contract violation in 4497 - restore failures returning 1 is a category of defect that could
affect any mutation harness in the repo. Worth a grep for similar finally blocks.
