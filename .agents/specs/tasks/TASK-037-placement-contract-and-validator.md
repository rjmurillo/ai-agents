# TASK-037: Placement contract doc extension and the memory placement validator

## Objective

Ship the two PRs DESIGN-026 defines: PR A extends
`templates/rules/knowledge-persistence.md` and `.serena/memories/README.md`
with the five-destination placement taxonomy, regenerates the four mirrors,
and commits; PR B adds `scripts/validation/check_memory_placement.py`, its
tests, and the `lefthook.yml` job, and records the full-corpus warning count
in the PR body.

## In/Out of Scope

In scope: the taxonomy section in `knowledge-persistence.md`, the "What
belongs here" section in `.serena/memories/README.md`, the four regenerated
mirrors, the new validator script, its test module, and the one new lefthook
job in the existing parallel memory group.

Out of scope, per REQ-028: any edit to `templates/rules/universal.md`; a
capability registry (#5396); a duplication or quality framework (#5397); a
token or context budget (#5400); any change to the orphan/unindexed
(#4313), inert-prose (#4776), or duplicate-target-path (#4705) validators; a
copied-contract evidence policy (#5399); reclassifying any of the 994
existing memory files.

## Acceptance Criteria

- [ ] `templates/rules/knowledge-persistence.md` contains a "Placement
      contract" (or equivalently named) section naming five destinations
      (rule, skill, agent, memory, delete/merge), each with a one-paragraph
      decision rule.
- [ ] `.serena/memories/README.md` contains a "What belongs here" section
      pointing at the taxonomy and documenting the suppression marker.
- [ ] All four generated mirrors
      (`src/claude/rules/knowledge-persistence.md`,
      `.claude/rules/knowledge-persistence.md`,
      `.github/instructions/knowledge-persistence.instructions.md`,
      `src/copilot-cli/instructions/knowledge-persistence.instructions.md`)
      are byte-identical to what `build_all.py` renders from the edited
      template.
- [ ] `templates/rules/universal.md` has zero changed lines in PR A's diff.
- [ ] `scripts/validation/check_memory_placement.py` exists, implements the
      CLI, skip list, four signals, classification thresholds, suppression
      marker, `--base` new-vs-existing policy, and exit codes DESIGN-026
      specifies.
- [ ] `tests/validation/test_check_memory_placement.py` exists and covers
      every case in DESIGN-026's Testing Strategy table.
- [ ] `lefthook.yml`'s existing `parallel: true` memory job group gains one
      new `memory-placement` job, globbed `.serena/memories/**/*.md`, with
      no change to the four existing sibling jobs' `run` or `glob` values.
- [ ] A full-corpus run (`--path .serena/memories`, no `--ci`) exits 0 and
      its normative/suspect/suppressed counts are recorded in PR B's body.
- [ ] No em dash or en dash in any changed file across both PRs.
- [ ] `uv run python scripts/validation/pre_pr.py` reports no BLOCKING
      finding on either PR's branch.

  already present as uncommitted working-tree changes on

  `.serena/memories/README.md`, and all four mirrors show modified). Confirm

  ```bash

  ```

- PR B (the validator, its tests, and the lefthook job) does not yet exist
  on disk as of this writing; build it against DESIGN-026's CLI, signal, and
  classification specification.
- Keep PR A and PR B as separate branches per the brief (`feat/5391-placement-contract`
  for PR A, `feat/5391-placement-validator` for PR B), both branched from
  `main` with no dependency on each other, with PR A's body reading
  `Refs #5391` and PR B's body reading `Closes #5391`. The spec files land
  in PR B first; PR A carries the same commit and merges cleanly after it.
- Keep each commit within the five-file advisory atomic-commit limit; PR A's
  six touched files (one canonical, four mirrors, one README) may need two
  commits (canonical plus README in one, the four generated mirrors in
  another) to stay under the limit.

## Testing Requirements

Positive: a new normative memory fails `--ci`; an existing normative memory
warns only; a suppressed file downgrades and is reported as suppressed.
Negative: `README.md` and `*-index.md` are skipped; a bad `--base` ref exits
2; a non-git directory exits 2. Contract: the full-corpus run exits 0 and its
three counts are recorded; `lefthook.yml`'s existing four sibling jobs in the
parallel memory group are unchanged in `run` or `glob` value.
