# Documentation review catch rate

These replays measure deterministic checks against past documentation review findings.
Each check owns its corpus, runner, results, and scoring explanation.

- `citation_freshness/`: Forward checks and inbound citation drift.
- `agent_skill_docs/`: Skill documentation coverage.
- `doc_date_drift/`: Documentation date drift.
- `links/`: Documentation links and style.
- `same-pr/`: Documentation accuracy within one pull request.
