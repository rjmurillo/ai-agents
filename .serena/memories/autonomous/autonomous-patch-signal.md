# Evidence: user patch as an understanding signal

<!-- placement: evidence; reason: records a collaboration signal and migration destination, not an operating contract -->

Source: PR #760.

## Observed evidence

The user supplied patches after the agent declared the fix complete. The patches
showed an incomplete understanding of the requirement and the solution space.

## Migration disposition

The host Universal Rules treat a user-supplied patch as a signal to verify
understanding before continuing. User Sovereignty still decides whether the
patch is an example, a requested change, or the intended implementation.
