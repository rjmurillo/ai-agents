# Agent Generation: Edit Locations

**Last Updated**: 2026-02-07
**Source**: User correction, session 1184

## Constraint (HIGH confidence)

When editing orchestrator or any agent file that has a shared template, edit
these 4 locations:

1. `templates/agents/` - Shared templates (single source of truth; edit first)
2. `.claude/agents/` - Claude Code agent definitions (hand-maintained copy)
3. `src/claude/` - claude-agents plugin copy (hand-maintained copy)
4. `.github/agents/` - GitHub Copilot self-host copy (hand-maintained copy)

**DO NOT manually edit**:
- `src/copilot-cli/` - Generated by `build/generate_agents.py`
- `src/vs-code-agents/` - Generated by `build/generate_agents.py`

Run `python3 build/scripts/build_all.py` after editing the template. It reads
the `.shared.md` templates and writes the two generated trees. It does **not**
write the three hand-maintained copies; those are yours to update.

## Corrections, verified 2026-07-31

Two errors in the original note are fixed above.

1. **The generator is Python, not PowerShell.** This note named
   `build/Generate-Agents.ps1`. The current generator is
   `build/generate_agents.py`, invoked through `build/scripts/build_all.py`
   (ADR-042 Python migration).
2. **`.github/agents/` was left as an open question and is now answered: it is
   hand-maintained and must be edited manually.** The original list of three
   locations omitted it, so following this note exactly would leave the GitHub
   Copilot self-host copy stale. `.agents/governance/GENERATOR-FILES.md`
   lines 31 to 33 list all three hand-maintained copies.

Negative control for the hand-maintained claim: revert only
`.claude/agents/orchestrator.md` to `origin/main`, run
`build/scripts/build_all.py` (exit 0), and the reverted content stays reverted.
A generated file would have been restored.

The cost of the omission is measurable. PR #1715 added an `Orchestration
Budget` section to the Claude copies only; three months later the template and
every Copilot-facing copy still lacked it. See
`.serena/memories/decision-agent-files-are-not-canonical.md`.

## Also applies to

Skills and commands use different pipelines. Skills are single-source under
`.claude/skills/` and mirrored by `build/scripts/generate_skills.py`; commands
use `build/scripts/generate_commands.py`. Do not carry the agent rule across to
them.
