# Skill Sidecar Learnings: Orchestrator

**Last Updated**: 2026-10-18
**Sessions Analyzed**: 2

## Observations (MED confidence)

- Subagents correctly refuse owner approvals relayed by the orchestrator. Evidence: decision D5 for PR #5992 `--approve-untrusted-config`. The orchestrator runs owner-gated commands itself and records the approval on the PR. (Session claude-session-0191QTCyqXgwVXfiZgDSfTcn, 2026-09-29)
- A user message sent mid-turn reached about 20 running workflow subagents, and each acted on it alone. The user asked for a label on human-blocked issues. The orchestrator created `blocked:owner-action`, and a subagent created `blocked:human`. A later audit removed 13 of 38 agent-applied labels as wrong. When a relayed request mutates shared state (labels, settings, issue bodies), one owner should act and the rest should report. (42-issue sweep, 2026-10-18)
- Out-of-credit reviewers fail every call, not some. The Codex workspace ran out early in the triage run, and all later GPT 5.6 Sol calls failed with "Your workspace is out of credits". That covered 26 of 42 triage checks and every PR review. Cursor's route to the same model hit a weekly usage cap. A one-call probe before launch shows the model responds, not that it has quota for the run. (42-issue sweep, 2026-10-17)
- Eureka, review convergence: more adversarial rounds did not converge an open-ended reviewer, but a frozen contract did. Six PRs went through 5 unbounded rounds each and still had 1 to 4 blocker or major findings, because every round raised new scope. One bounded round on the same six PRs counted only defects the diff introduced plus unmet acceptance criteria, and listed everything else as flagged notes. It found 0 counted findings on four PRs and 1 real defect on two (#6681: a fail-open in `tests/hooks/managed_image_marker_parsers.py`; #6676: its own defect, not recorded here). The usual advice is to review again until clean. The evidence says to freeze what counts as a finding first. (42-issue sweep, PRs #6676 #6681 #6686 #6687 #6690 and ubuntu-machine-config #220, 2026-10-18)
- Eureka, pre-written amendments: ADR-083's Review Date section pre-wrote the amendment it expected ("the tag plus the dogfood install were the durable outcome"). The tag never shipped. A date bump that copied that sentence would have recorded a false fact. The 2026-10-18 review re-measured the criteria instead and recorded what the evidence showed (issue #6742). When a review date section holds a ready-made outcome, treat it as a hypothesis and re-measure before copying it. (42-issue sweep, ADR-083 review, 2026-10-18)
