# Measured Contradiction Deliverable

A measured contradiction can matter even when the team decides against shipping.
Future readers need the result and its limits, not just the verdict.

## Acceptance criteria

1. An in-scope measurement contradicting prior guidance triggers the deliverable.
2. The final reply states the measured values on one `Surprise:` line.
3. The contradiction log captures the evidence in a committed `decision-<slug>` record.
4. If Serena fails, write the file directly. If persistence is blocked, report why.
5. The rule applies on a do-not-ship verdict. Confirming prior guidance triggers nothing.
6. The existing task completion predicate remains authoritative. Do not expand investigation scope.
7. Generated rules and their fixture reflect the source without raising instruction budgets.
