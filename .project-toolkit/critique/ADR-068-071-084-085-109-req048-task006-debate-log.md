## Live AC-17 run and owner decision D28

The first live run (Claude Code 2.1.318, 2026-11-04) failed: the Stop hook never wrote a marker. The CLI registered 22 hooks and skipped ours.

- Cause: the build rendered the plugin hooks file to `src/claude/hooks.json`, at the plugin root. Claude Code auto-discovers plugin hooks only at `<plugin-root>/hooks/hooks.json`.
- A `hooks` key in `plugin.json` also loaded the file. The repo bans that key (`build/scripts/validate_plugin_manifests.py`, issue #1833: CLI 2.1.122 broke every install over it).
- Owner decision D28 (2026-11-04): render to `src/claude/hooks/hooks.json`, and make `.claude/hooks/hooks.json` a relative symlink to it. ADR-109 section 2 records the amendment.
- After the move the live e2e passed: 3 passed, marker written, `/retrospective` in the CLI stream, no advisory text in model context records.
- README and four docs said the plugin "registers no hooks (ADR-097)". They now say Claude Code gets one advisory Stop hook (ADR-084 rule 2a), Copilot gets none, and neither gets tool-use hooks (ADR-097).
