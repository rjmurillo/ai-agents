## Traps this session paid for, so the next one does not

- **A bare `lefthook run pre-push` measures almost nothing.** lefthook expands
  the hook's first positional argument into `{1}`, and `push-ref-staleness`
  reads it as the remote name. Without `--hook-arg origin --hook-arg <url>` the
  placeholder stays unexpanded, that job rejects it, and the piped hook aborts
  four jobs in at 0.4 seconds against a declared 3,330.
- **`--force` defeats the change classes.** It runs every job regardless of its
  glob, so `python-type-check` runs mypy over a markdown file and fails, and
  every class measures the same job set. It is opt-in for that reason, and the
  artifact records whether it was used.
- **Several pre-push jobs declare `use_stdin: true`.** With empty stdin they
  take an early exit. Supply `--stdin-ref-line` with what git would feed the
  hook.
- **The container clone is shallow and `push-ref-policy` rejects that.**
  `git fetch --unshallow origin` took 14 seconds and is a precondition for any
  pre-push measurement here.
- **You cannot replay an old SHA's pre-push to completion.** A worktree at the
  baseline SHA is behind `main`, so its count ratchets evaluate against a base
  that has moved and the hook aborts after 9 jobs. This is why no paired
  measurement exists.
- **A pre-commit run mutates the tree.** `memory-token-update` rewrites
  `.serena/memories/memory-index*.md`. The sampler records `tree_mutated`;
  restore between runs or the later repetitions measure a different tree.
- **The taste count ratchet counts the whole tree, including files you stage.**
  Two of this session's pushes were blocked by it: once by a `# type: ignore`
  added in a test, once by a source file crossing 500 lines. Find the offender
  with a whole-tree `(file, rule)` diff against `origin/main`, per
  `ci-scripts.md` MUST-15, not by reading warnings. Never raise the baseline.
- **Committed JSON over 500 lines trips the same ratchet** and JSON cannot
  carry a suppression comment. The sampler's JSON companions are deliberately
  not committed; the markdown carries every figure.
