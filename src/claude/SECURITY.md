# Security Policy

This plugin ships from the `main` branch of
<https://github.com/rjmurillo/ai-agents>. Only the latest `main` is supported.

Report a vulnerability privately through GitHub:
<https://github.com/rjmurillo/ai-agents/security/advisories/new>

Do not open a public issue for a vulnerability. The full policy is in the
repository root `SECURITY.md`.
